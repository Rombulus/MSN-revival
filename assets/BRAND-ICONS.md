# Logos des réseaux

Les chemins SVG des logos WhatsApp, Messenger, Instagram, Signal, Telegram, Discord, Google Messages, Google Chat, X, Apple et Matrix proviennent du projet [Simple Icons](https://github.com/simple-icons/simple-icons), distribué sous [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

Les formes de repli Messenger, LinkedIn, Slack, Google Messages, Teams et discussion générique sont dessinées localement si l’entrée n’est pas disponible. Les noms et logos permettent d’identifier le réseau d’une conversation.

Les logos sont intégrés dans `legacy-icons.svg` ; aucun service externe n’est appelé pour les afficher. Le script `tools/update-brand-icons.mjs` permet de régénérer cette partie du fichier depuis les sources.
